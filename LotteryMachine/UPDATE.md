# 更新记录

**每次发版本必须在这里加一条新记录**，格式：`## {semver} — {发布日期}`，下面列出这次改了什么。
`version.json` 里的 `semver` 字段必须始终等于本文件最新一条记录的版本号——两处不同步就分不清哪个是真的当前版本。
设置页「版本信息」展示的就是 `v{semver}（{精确时间戳}）`，时间戳用于更新检测判重（见 PROJECT.md 第六节），
不需要手动对应到这里的日期。

## 1.1.1 — 2026-09-03

- 新增：权重公式可在设置页自定义（支持 `+ - * / ( )` 四则运算），默认仍为 `160-g`（`g` 代表成绩），提供"重置为默认"按钮；公式解析失败时红色 toast 提示并恢复上次保存的内容
- 变更：更新检测由"软性提示、可跳过"改为强制更新弹窗——弹窗展示最近三个版本的更新内容（`version.json` 新增 `changelog` 字段），没有"取消/跳过"选项，唯一操作是点击"Click here to finish update"完成更新（清缓存并刷新页面）
- 变更：转盘旋转动画改为"匀速 x 毫秒转固定圈数 + 固定 y 毫秒匀减速停下"两阶段节奏（原来是固定时长的单段缓动），x（毫秒）、圈数、y（毫秒）均可在设置页调整（**y 曾经试过在 [y/2,y] 内随机取值，实测反而容易有"突然刹车"的观感——减速要走的距离差不多，时长被随机砍半时起始速度就要翻倍去追、减速曲线陡峭得多，改回固定 y 后减速节奏才稳定，悬念感改由落点随机来提供**）；旋转动画同时从 CSS `transition` 改为 `requestAnimationFrame` 逐帧驱动，不再依赖 `transitionend` 事件，同时保留 `setTimeout` 兜底（标签页切到后台时 rAF 可能整个暂停，兜底避免转盘卡死点不动）
- 优化：设置页"🎯 抽奖设置"卡片按"转盘节奏 / 中奖提示 / 操作方式"分组加了小标题和分隔线，避免几块内容堆在一起显得乱
- 新增：中奖弹窗加了 10 种随机庆祝动效（撒花、冠军奖杯、举手欢呼、烟花、气球、彩带、星光闪烁、鼓掌、派对礼炮、皇冠），每次中奖随机触发一种
- 修复：转盘指针以前每次都精确停在中奖扇区正中间，看多了会让人觉得"像是设计好的"；改为在扇区范围内随机取一点停靠，不影响中奖结果本身
- 调整：落点分布从"扇区内均匀随机 + 12% 安全边距"改为"以中点为轴心 1.1 倍拉伸后再 clamp"（边距缩到 1%），让指针更容易停在靠近扇区分隔线的位置、悬念感更强，同时约 10.9% 的抽奖会精确卡在边界值（早期测试过 2 倍拉伸，卡边比例高达 50%，太夸张，改成了 1.1 倍）
- 新增：匀速阶段圈数（原来固定 3 圈）现在支持小数，比如设成 0.5 圈
- 调整：转盘节奏默认值改为 x=400ms / 圈数=1 / y=2500ms（原来是 x=1000ms / 圈数=3 / y=1000ms），匀速阶段更短、减速悬念阶段更长
