班级抽奖点名机

一个课堂随机点名/抽奖小工具：把全班同学的照片和名字放到转盘上，按权重（可以和成绩挂钩）随机抽取一位同学来回答问题。所有数据保存在你自己的浏览器里，也可以导出备份或同步到你自己的 OneDrive，不会上传到任何第三方服务器。

📋 三个页面总览

页面作用
抽奖展示转盘，点击中心按钮开始抽奖，选出一名同学
录入维护学生名单：姓名、照片、成绩、权重
设置调整抽奖动画时长、数据备份、安装到桌面等通用设置

三个页面共享同一份"班级"数据——你可以在页面左上角切换/新建/管理多个班级，互不影响。

🎡 抽奖页

转盘上每个扇区代表一名学生（照片+姓名）。点击转盘中心的"开始抽奖"按钮，转盘会旋转一段时间后停下，指针指向的同学就是中奖者，会弹出照片+姓名的提示框。

  • 至少需要 2 名学生才能开始抽奖。
  • 默认情况下抽奖结果有放回：同一名同学可能连续被抽到多次（不会因为抽过就被排除）；如果不希望重复，可以开启下面的「不重复抽取」。
  • 转盘旋转多久、中奖弹窗多久自动消失，都可以在「设置」页调整。

等权抽取

转盘上方工具栏有一个「⚖️ 等权抽取」按钮，默认关闭（灰色）；点击一下切换成开启（变成蓝色高亮），再点一下变回关闭，跟「🔄 重置」是同一套按钮样式，点哪个按钮开着就是蓝色的。

关闭时：每个人被抽到的概率 = 该学生权重 ÷ 全班总权重（权重越高越容易被抽到）。
开启后：忽略所有权重，每个人被抽到的概率完全相同——适合"这次就想公平抽签，不看成绩权重"的场合。

这个开关只影响"这次抽谁"，不会修改任何学生的权重数值，随时可以开启/关闭。

不重复抽取

「等权抽取」右边还有一个「🚫 不重复抽取」按钮，默认关闭，点击方式和「等权抽取」一样（点亮=开启）。

开启后：每次抽奖结束，中奖同学对应的扇区会变灰，之后的抽奖只会在"还没抽过"的同学里进行，直到全班都抽过一轮为止（再点"开始抽奖"会提示"已全部抽完"）。

开启「不重复抽取」后，它右边会出现一个「🔄 重置」按钮：

  • 点击重置：清空本班"已抽过"的记录，所有灰色扇区恢复原状，可以重新抽一轮。
  • 关闭「不重复抽取」：同样会自动清空已抽过的记录，恢复原状。
  • 切换班级不会触发重置：每个班级各自独立记录"抽过谁"，从 A 班切到 B 班再切回来，A 班已经变灰的同学还是灰的，不会被清空。

「等权抽取」和「不重复抽取」可以同时开启，互不冲突：开启「不重复抽取」时，「等权抽取」只对"还没抽过的人"生效。

抽奖快捷键

如果你用翻页笔/演示遥控器上课，不想每次都跑去点鼠标，可以用快捷键触发抽奖：默认快捷键是 PageUp（绝大多数翻页笔的"下一页"键发送的正是这个键），在「抽奖」页任意时候按下就等同于点击转盘中心的"开始抽奖"。想改成别的键，去「设置」页的"抽奖设置"卡片里点"🎹 录入键盘快捷键"，按下你想用的新键即可（详见下方设置页说明）。

快捷键只在「抽奖」页生效，切到「录入」「设置」页不会误触发。

抽奖音效与庆祝动效

转盘旋转期间会随机播放一段抽奖音效，并自动匹配本次旋转的时长；指针停下、公布中奖者的同时，会随机播放一段中奖音效（原速播完）。中奖弹窗还会随机触发一种庆祝动效（撒花/奖杯/欢呼/烟花/气球等，每次随机换一种），增加课堂氛围。

不想要声音的话，去「设置」页「抽奖设置」里关掉「🔊 开启抽奖音效」开关（默认开启）即可，庆祝动效不受这个开关影响，会一直保留。

首次打开应用（或音效素材有更新）时，会看到一个带进度条的加载遮罩，等音效素材下载/校验完成才能进入操作——这是为了保证第一次抽奖时音效就能正常播放，不会出现"声音卡顿/播不全"。素材已经缓存过的话，这个遮罩通常只会一闪而过。

📝 录入页

在这里维护当前班级的学生名单。点击「添加学生」新增一位，或直接在已有的卡片上修改姓名、成绩。工具栏一共四个按钮（颜色统一，方便识别是一组操作）：

  • 📄 TXT 批量导入：见下方"TXT 批量导入"说明。
  • ➕ 添加学生：新增一位空白学生卡片。
  • ☁️ 打开 OneDrive 备份：效果和设置页里的入口完全一样，打开备份弹窗（可上传/查看历史/恢复）。
  • 🔄 立即同步：不用打开弹窗，一键把当前所有班级数据直接上传一份新备份到 OneDrive。如果还没登录，会提示你先登录（自动打开备份弹窗引导登录）。

录完名单顺手点一下「🔄 立即同步」是个好习惯，不用像以前一样打开弹窗再点上传。

成绩与权重

每个学生有一个「权重」，权重越高，被抽到的概率越高。权重有两种来源：

模式说明
按成绩自动计算默认权重 = 160 − 成绩（分数越低，权重越高，最低不小于 1）。填了成绩后权重会自动算好，不用手动改。
手动设置勾选卡片上的「手动设置权重」后，可以自己填任意权重数字，不再随成绩变化。

举例：小明考了 98 分 → 权重 = 160 − 98 = 62；小红考了 130 分 → 权重 = 160 − 130 = 30。分数越不理想的同学，本轮被抽中巩固知识点的概率就越高。

「160 − 成绩」这个公式本身也可以改：去「设置」页左栏「权重公式」输入框里，用 g 代表成绩，写一个支持 + − × ÷ ( ) 四则运算的表达式（比如 200-g*1.5），保存时会自动校验公式是否合法，公式错了会有提示且不生效；点「重置为默认」可以随时改回 160-g。改完公式，所有按成绩自动计算的学生权重会立即重新计算。

照片与裁剪

点击学生头像右下角的 ✎ 图标可以上传照片，上传后会弹出一个裁剪框：拖动图片调整位置、拉动下方滑块缩放，最终会裁剪成 1:1 的正方形头像用在转盘上。

TXT 批量导入

如果你手头已经有一份成绩单，或者只是想快速导入一批姓名，可以用「TXT 批量导入」一次性导入，不用一个个手填。支持两种文件格式，每次导入只能用其中一种，不能混用：

格式写法成绩
A. 姓名 + 成绩 每行一个学生，姓名和成绩之间用 Tab 键分隔（⚠️ 不能用空格分隔，空格不算分隔符） 按你填的成绩计算权重
B. 只有姓名 每行一个姓名，不带任何成绩或分隔符 统一按 130 分算权重

格式 A 示例（姓名和成绩之间是 Tab，不是空格；从 Excel 复制一列姓名一列成绩粘贴过来天然就是 Tab 分隔，可以直接用）：

徐佳莹	98
李涛	107
张伟	85

格式 B 示例：

徐佳莹
李涛
张伟
⚠️ 两种格式不能在同一个文件里混用。如果导入时既有"姓名+Tab+成绩"的行，又有"只有姓名"的行，会弹出"数据格式冲突"提示，逐行列出哪一行是什么问题，需要你把文件改成统一格式后再重新导入，不会帮你部分导入。常见的问题行：姓名和成绩之间用的是空格而不是 Tab、成绩写的不是数字、一行里有超过一个 Tab。

格式没问题的话，导入前会弹出预览：

  • 全新姓名会被直接新增，不需要额外确认；
  • 名单里已经存在的姓名，会单独列出来，默认勾选"覆盖"——如果你不想用新数据覆盖某个人的原有数据，取消勾选那一行即可（也可以用"全部覆盖 / 全部跳过"一键批量选择）。

🏫 班级管理

抽奖页和录入页左上角都有一个班级切换器（🏫 图标 + 当前班级名），点击展开面板可以：

  • 切换班级：点击列表里的班级名称即可切换，每个班级的学生名单完全独立。
  • 新建班级：点击「➕ 新建班级」，输入新班级名称。
  • 重命名：点击班级行的 ✎ 图标。
  • 删除班级：点击 🗑️ 图标（至少要保留一个班级，删除最后一个班级会被拒绝）。
删除班级会连同该班级下的所有学生数据一起永久删除，操作前会二次确认，建议先在「设置」页导出备份。

⚙️ 设置页

设置页分两栏：左边是「抽奖设置」和「安装与存储」，右边是数据备份、云备份、版本信息、危险区域这几个相对独立的功能块。

「抽奖设置」卡片里除了转盘时长、中奖弹窗自动关闭时间，还有抽奖快捷键的录入入口：点击"🎹 录入键盘快捷键"，按钮会变成"请按下要设置的按键..."，这时按一下你想用的键（比如翻页笔的按键）就设置成功了；按 Esc 可以取消，保留原来的快捷键。

数据导入导出

「导出数据」会把所有班级的学生名单和设置打包成一个 JSON 文件下载到本地，文件名格式为「年-月-日--时-分-秒」；「导入数据」可以选择一个之前导出的 JSON 文件，把当前数据整体替换掉（会有二次确认，避免误操作覆盖）。

建议养成习惯：换电脑、清理浏览器数据前，或者每次考试录完成绩后，顺手导出一份备份。

OneDrive 云备份

点击「打开 OneDrive 备份」，登录你自己的 Microsoft 账号后，可以把数据上传到云端（默认文件名同样是"年-月-日--时-分-秒"），也可以从历史备份列表里选一份下载恢复。历史记录按最新在前排列，一页显示 10 条，可以翻页查看更早的备份。

数据只会保存在这个应用专属的 OneDrive 文件夹里，不会读取或修改你 OneDrive 里的其他文件。

安装到桌面 / 持久化存储

在支持的浏览器（Chrome / Edge 等）里，点击「安装到桌面」可以把本应用安装成一个独立窗口的桌面/开始菜单快捷方式，打开体验更接近原生应用。如果按钮显示"暂不支持"，通常是因为浏览器不支持、或者已经安装过了。

应用还会自动申请"持久化存储"权限，降低浏览器在磁盘紧张时自动清空本应用数据的概率——但这不是 100% 保险，仍然建议定期导出备份或使用 OneDrive 云备份。

版本与更新

网页每次更新后，打开应用如果检测到有新版本，会弹出更新提示弹窗，展示最近的更新内容，弹窗上有三个按钮：

按钮效果
完成更新立即清缓存并刷新页面，马上用上最新版本。
Maybe Later这次先不管，直接关掉弹窗；下次打开应用还会再弹一次。
Skip This Version跳过这一个具体版本的提醒，直到下次真的有新的更新才会再弹窗。

设置页也有「🔄 检查更新」按钮：点击会直接弹出更新弹窗展示当前最新版本的更新内容，不需要等"服务器上有新版本"才会弹（跟应用自动检测不一样，自动检测只在真的有新部署时才提示）。如果是在本地开发环境或暂时离线，会提示"未检测到部署信息，无法检查更新"。

❓ 常见问题

抽奖结果好像不太公平？

先检查是否勾选了「等权抽取」；没勾选的话，权重高的同学（一般是成绩相对较低的同学）本来就更容易被抽到，这是设计如此，用来照顾需要多巩固的同学。如果只是想公平抽签，勾选「等权抽取」即可。

换了浏览器/电脑，数据不见了？

数据默认保存在当前浏览器里，换设备不会自动带过去。请提前用「导出数据」或「OneDrive 云备份」，在新设备上用「导入数据」/OneDrive 恢复。

OneDrive 登录不了？

请确认使用的是允许弹窗的浏览器环境，并且用你自己的 Microsoft 个人账号登录；如果一直失败，可以改用「导出数据」的本地备份方式代替。

清浏览器缓存/Cookie 会不会丢数据？

清"浏览历史记录"不会影响数据；但清"Cookie 和其他网站数据"会连带清空本应用的数据，操作前请务必先导出备份。
