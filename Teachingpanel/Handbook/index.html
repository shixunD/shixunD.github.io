快速开始

  1. 在「主页 → 学生名单」点 批量添加，把「学号 姓名」两列从 Excel 复制粘贴进去。
  2. 每天在「作业」里 新建作业，只需点出没完成的同学（默认全班都是完成）。
  3. 在「背诵」里建一个 轮次（一篇课文/一组古诗），每天抽查几个人并登记结果。
  4. 考完试在「考试」里新建考试，粘贴「姓名 成绩 班级排名 年级排名」即可导入。
  5. 定期在主页点 导出全部数据 备份一次。
所有数据只保存在你当前使用的这个浏览器里，不会上传到任何服务器（除非你主动使用 OneDrive 备份）。

主页

顶部四个概览卡片：今日背诵剩余人数（今天还有未完成背诵计划的学生）、今日作业未补（今天布置的作业里还没补上的人次）、本周背诵剩余人数（本周轮次里，状态不是提前完成 / 完成过关 / 条件过关的学生人次）、本周作业未补（本周布置的作业里还没补上的人次，一人一份作业算一次，累加）。点击卡片直接跳到对应页面。新建 / 编辑背诵轮次时需要选择这个任务设定的具体日期：弹出的日历可前后翻月，点任意一天即选中那一天，它所在的那一周会同时高亮（按周粗略分组，按具体日期精细排序）。

学生名单

  • 名单始终 按学号从小到大 排列。
  • 姓名在同一个班里必须唯一（成绩导入靠姓名匹配）。重名学生请加后缀区分，例如「张三B」。
  • 批量添加支持「学号 姓名」「姓名 学号」或只写姓名（自动接着最大学号编号）；已存在的姓名会跳过。
  • 点击任何地方的学生姓名都会跳到该生的 学生趋势。
  • 中途转入的学生：添加或编辑时填 入班日期（班里已经有作业时，新添加的学生默认填今天）。这天之前布置的作业不算该生：登记页不出现该生的卡片，总览里显示灰色格子，不计入完成率、欠交清单、学生趋势和导出统计。从开学就在班里的留空即可。
  • 转出：名单里点「转出」。该生不再出现在作业、背诵、考试的登记和统计里，也不计入导出统计，但以前的所有记录都保留。名单底部「已转出」里可以随时 恢复在读，点姓名也能看该生以前的学生趋势。
  • 删除学生会同时删除该生的全部作业、背诵、考试记录，不可恢复。只是不在这个班了的话，用「转出」。

多班级

顶部导航栏的「🏫 班级名 ▾」可以切换、新建、重命名、删除班级。每个班级的学生和记录相互独立。

顶部导航栏始终固定在最上面，不随页面滚动；页面滚动、滚动条都只在导航栏下面的内容区里。

导出统计（作业加减分 + 背诵过关）

  • 主页「📤 导出统计」卡片 → 导出班级学情：左边勾选作业（勾分组夹 = 全选里面的作业，也可以单独取消某一项），右边勾选背诵任务（可多选，也可以不选）。下方立即显示预览，再点 PDF（打印）、Excel、Markdown 或 复制 Markdown。每次打开都一项不勾（不会沿用上次的选择），自己勾选；最上面的「全选全部内容」一次勾上所有作业和背诵任务，每栏表头的「全选」只管这一栏，每个分组夹前的复选框管这个分组夹，再点一次就取消全选，只勾了一部分时显示半选（横杠）。导出窗口大小固定，预览和两栏列表都在框里滚动。
  • 同一张卡片的 导出个人学情：先选一位学生，再勾选作业和背诵任务，生成这位学生的个人学情——每项作业写明完成情况（按时完成 / 未完成 / 已补交……）和备注，每项背诵写明当前情况、是否过关、最近检查日、检查次数和待完成计划。不计加减分。同样支持 PDF / Excel / Markdown / 复制 Markdown，勾选方式和班级学情一样（每次打开一项不勾，有全选框）。
  • 作业加减分（班级学情）：一次导出算一个统计周期，N = 勾选的作业总数（不管来自几个分组夹）。全部 N 项都是绿色 +2 分；只差 1 项不是绿色 +1 分（N 至少为 2 才有这一档，N = 1 时只有「绿色 +2 / 否则 0」）；未按要求完成（粉）每项 −0.5，未完成（红）每项 −1；已补改、已补交（蓝）不扣分，但不算绿色。最终得分 = 加分 − 扣分。
  • 背诵加减分：每个背诵任务一列，表头是任务全名，格子里是该任务的得分。最新一次检查是提前完成 / 完成过关 / 条件过关就算过关（过关之后又多出来的计划多半是误操作，不影响，也不算进计划次数）。有「提前完成」记录 +3；没有计划，或只有一次计划且计划当日过关 +2；有多个计划日期、或计划当日没过关（包括当天过关后又被判重新过关）但最终过关 +1；最终没过关（计划中 / 重新过关 / 未过关 / 未检查）−2。报表最后一列是「总分」（作业得分 + 各背诵任务的得分）。
  • 报表内容：汇总表（学号、学生、各状态数量、加分、扣分、最终得分、背诵 ✓/✗）、全班总分 / 人均 / 全部按时完成人数 / 部分按时完成（差一项）人数、逐项明细色块、背诵未过关名单、仍未补交 / 未补改名单。可按学号或按最终得分排序，标题可以自己改。
  • PDF：会打开浏览器的打印窗口，「打印机 / 目标」选「另存为 PDF」。Excel 有三张表：汇总、逐项明细（格子底色 = 状态）、说明与名单。PDF / 预览里，逐项明细表下方有「作业状态」「背诵状态」两行图例。导出（班级学情和个人学情，PDF、Excel、Markdown 都一样）里背诵只分过关和没过关：提前完成 / 完成过关 / 条件过关照常显示，重新过关、未过关、计划背诵、未检查一律显示成红色「未过关」；这只是导出的显示方式，应用里的状态和加减分都不变。PDF 每页底部自带页脚（左边班级和报表名，右边「第 X 页 / 共 Y 页」）；打印窗口「更多设置」里记得取消勾选「页眉和页脚」，不然浏览器会另外印上网址和时间。Excel 已设好 A4、缩放到一页宽、每页重复表头，页脚同样带页码。Markdown 里状态直接写文字（按时完成×5、已补交×1……）。
  • 分值可以改：主页「⚙️ 设置 → 导出统计：加减分规则 → 调整」。可改全绿加分、差一项加分、四种非绿色状态各自每项扣几分、背诵四档的分值，以及「条件过关算不算过关」「过关后还有未完成的计划是否判不过关」。
  • 报表里的日期统一写成「11月6日（周五）」，头部写明统计范围（所选作业 / 背诵最早到最晚的日期）和导出时间。个人学情和班级学情用同一套版式：顶部标题和徽标、汇总卡片（按时完成 5/6、已补交 / 已补改、仍未完成、背诵过关），下面是作业和背诵两张表；Excel 里作业、背诵各一张表。
  • 统计以导出那一刻的状态为准。没登记过的学生默认是「按时完成」。填了入班日期的学生，入班前的作业显示灰色「入班前」、不计入，加分档按该生入班后的作业数算（比如入班后有 2 项、都是绿色，就算全部按时完成 +2）。转出的学生不出现在报表里。

comment 快捷词

  • 主页「💬 comment 快捷词」卡片里可以添加、编辑（✎，回车保存、Esc 取消）、删除（会先二次确认）、调整顺序（↑↓）。作业和背诵是两套独立的快捷词。
  • 背诵默认有：复习体系混乱、复习体系有条理、书写有一定问题、格式需要改善；作业默认为空，按需添加。
  • 登记作业状态或背诵检查时，点一下快捷词就会 追加 到 comment 末尾（自动用「；」隔开），还可以继续手动输入。

数据备份

  • 📤 导出数据库（.db）：得到一个数据库文件（文件名是导出时间，如 2026-10-29--14-30-05.db），包含所有班级、学生、作业、背诵、考试、计划、学情记录和设置。换电脑时在新电脑上点 📥 导入数据库 选择这个文件即可完整恢复。
  • 这个 .db 是标准的 SQLite 数据库，可以用免费的 DB Browser for SQLite 等工具直接打开，按表（students 学生、homework 作业、homework_records 作业登记、rec_checks 背诵检查、rec_plans 背诵计划、exam_scores 成绩……）查看数据。
  • 导入会 覆盖 当前全部数据，导入前建议先导出一份。选错文件（不是本应用导出的数据库）时会提示错误，当前数据不会被改动。
  • 备份提醒：「💾 数据」卡片上显示上次备份的时间和方式（下载到本地 / OneDrive），以及之后数据有没有改动。每天第一次打开时，如果上次备份之后数据有改动，会弹出「该备份了」，可以直接 下载到本地 或 上传到 OneDrive，也可以「稍后再说」（当天不再提醒）。没有改动就不打扰。下载到本地只能确认浏览器开始下载了，请自己看一眼文件保存好了。
  • OneDrive 云备份：每次上传都是一份新的带时间戳的 .db 快照，可在历史列表中选择任一份恢复（覆盖本地）。它不是自动双向同步。首次使用时点「☁️ OneDrive 云备份」→「登录 OneDrive」，用个人 Microsoft 账户登录并同意授权即可；应用只能读写 OneDrive 里「应用 / TeachingPanel」这一个文件夹，看不到你的其他文件。

登记

  • 调整作业顺序：左侧作业列表可以按住某一项上下拖动换位置（拖到目标的上半部分 = 插到它前面，下半部分 = 插到它后面）。拖过之后顺序会记住；之后新建的作业仍排在最上面。这只影响左侧列表的显示顺序，趋势、统计仍按日期计算。
  • 分组：点列表上方的「＋ 分组」新建一个分组夹（可以用来分单元、分阶段）。把作业拖到分组夹的标题上就放进去了，拖到分组夹里某一项的上 / 下半部分可以排到它前 / 后，拖到列表最底部的空白处可以移出分组；分组夹本身也可以拖动换位置。点分组夹的标题可以折叠 / 展开，右边的 ✎ 重命名、✕ 删除（只删分组夹，里面的作业会回到列表里，不会被删除）。
  • 点 新建作业，日期直接点 本周一～日、下周一～日 的日期块（默认今天，找不到再用日历框），填标题（可留空自动命名）。
  • 点击学生卡片 → 选择状态并写 comment（可以点快捷词快速填入）。
  • 红色/粉色卡片右上角的 「补」：学生补交后点一下，在弹出的确认框里点「确认已补上」，才会变成对应的蓝色；点错了可以点提示条上的「撤销」。

总览

学生 × 作业的色块表，一眼看出谁经常没完成。可按时间范围筛选；带白色小角的格子有 comment；最右列是"未补上"数量。列的顺序和分组跟左侧列表一致：同一分组的列上方有分组名，点分组名可以折叠 / 展开；按住列头左右拖动可以调整列的顺序（和左侧列表是同一个顺序：左侧列表靠前的，总览里靠左）（和左侧列表共用，折叠后该分组缩成一列，显示每个同学在这组里未补几项）。

欠交清单

按 作业 分组列出还没补上的同学（红/粉），最新的作业在最前面；点作业标题可跳到该作业的登记页。

学生补交后点「已补上」，确认 后才会生效；之后页面顶部会出现提示条，8 秒内点「撤销」即可恢复原状态（comment 也会保留）。

学生趋势

作业登记页的统计行并排显示「按时完成 xx% | 补改完成 xx%」（补改完成含已补交 / 已补改）。

在导航栏「📈 学生趋势」页的「📝 作业趋势」块里看：某个学生的按时完成率、最终完成率（含补交）、各状态次数、时间轴色条、每周完成率折线和全部 comment。

背诵情况

背诵按 轮次 管理：一个轮次就是一项背诵任务（例如「第三单元古诗两首」），不分日期——每天能查几个就查几个，每次检查都会记录日期。

颜色含义
灰还没检查
深绿提前完成（过关里做得特别好的，统计时算作过关）
绿完成过关
黄需要重新过关
红未过关
浅绿条件过关（勉强过关，算作过关但不太理想）
浅天蓝已安排计划背诵（卡片上显示计划日期和星期）
粉色边框今天需要检查（今天有背诵计划——不管是第一次背还是重新过关）

检查

  • 左侧选轮次，点学生卡片登记（打开时检查日期默认是今天：今天已有检查记录就自动选中它的结果并载入备注，没有就结果留空，要自己点；点掉已选的日期（再点一次）就不登记这次的检查结果，只处理计划，再点一次已选的日期可以取消；日期块里「今天」是灰色粗边框）：结果（提前完成 / 完成过关 / 条件过关 / 重新过关 / 未过关，再点一次可取消）、检查日期、备注；检查日期下面是 🗓️ 计划背诵日期（不用再点开关，选了日期就是要计划；该同学已有的计划日期会直接显示为选中，再点一次就取消）。每个日期只有一个检查状态、一个计划：点到已有记录的日期会自动载入那天的结果和备注可以直接改；改了没保存就关窗口时会提示。左侧的轮次可以 按住拖动 调整上下顺序；也可以像作业一样用「＋ 分组」建分组夹，把轮次拖进去 / 拖出来，点分组夹标题折叠 / 展开。
  • 重新过关表示还要再背：可以顺便在「🗓️ 计划背诵日期」里点选哪天再背（可多选，会加入背诵计划）；不选日期也能直接保存。未过关是这一轮的最终结论，不带日期：选了未过关，检查日期和计划日期都会隐藏，保存后卡片和记录里只显示「未过关」，不显示日期；保存后这一轮对这个同学就归档了（见下一条）。
  • 日期都用日期块点选：弹窗里直接列出 本周一～日、下周一～日 的日期块（标注具体日期和星期），点一下即可；实在不在这两周内，再用最下面「其他」的日历框选。检查日期默认就是今天，只能选今天及以前。
  • 学生的当前颜色 = 最近一次检查的结果（有未完成的计划时底色浅绿，状态用小圆点标出）；卡片上同时显示状态、最近检查日期和计划日期（多个计划时显示 +N）。学生名字后面的「(x次)」是这个同学在所有背诵任务里提前完成、完成过关、条件过关的总次数（已归档的也算）。弹窗底部的「本轮记录」把这一轮的计划和检查记录合成一条时间线，（还有笔记）最新的日期在最上面：先按记录的日期（笔记按你选的日期），同一天按添加的先后，后加的在上面。检查记录登记错了可以点 编辑（修改结果、检查日期、备注，保存后回到检查弹窗），或点 删除；计划可以取消。计划日期当天或之后有过关的检查、或之后又检查过，这条计划就变淡并显示「✓ 已检查」，保存后马上生效（计划当天只判了重新过关 / 未过关、又在当天加了计划，表示当天还要再背，要等再检查一次才算）。
  • 添加笔记：检查弹窗里的「📝 添加笔记（状态不变）」任何状态下都能用（未检查、重新过关、已归档都行），可只记文字、照片或语音，状态不变。点了以后会出现笔记日期（默认今天，可点日期块或用「其他」的日历选）。笔记显示在卡片上（灰点「笔记」）和弹窗底部的「本轮记录」里，可编辑（能改日期）、删除；计划不受影响。
  • 归档：最近一次检查是提前完成、完成过关、条件过关或未过关时，这一轮对这个同学就结束了（归档）：不能再登记其他状态、不能再加计划日期（之前已有的计划保留），只能修改那条记录的备注和照片；想改状态要先删掉这条记录，删掉后就解除归档。「🗓️ 计划背诵」里归档的同学名字卡变灰、点不了。只有「重新过关」不归档。之前登记过重新过关 / 未过关的同学不能再选提前完成。不能选的按钮会变灰。
  • 筛选按钮可以只看未检查、重新过关、未过关、完成过关、提前完成、条件过关的同学。

计划背诵

提前安排某个同学哪天来背。有两种方式：

  • 点学生卡片，在检查弹窗里的 🗓️ 计划背诵日期 选日期（可以选多个），会显示在「背诵趋势 → 检查历史」里（检查历史按背诵任务设定的日期排序（近的在前），再按任务所属的周分组（不是检查日期），相邻两周之间有一根虚线分隔；左边的竖线把同一个背诵任务的记录串在一起，不同任务各一条线）。它和检查结果互不影响：可以只加计划，也可以同时登记过关/重背/未过关并加计划。
  • 背诵页顶部的 🗓️ 计划背诵 子标签：选轮次 → 点日期 → 点学生，就加入这天的计划；再点一次取消，自动保存。 已计划但还没过关的同学，名字卡左侧的色条是天蓝色（其他按状态显示颜色）；选中某一天时，这天有计划的同学多一圈蓝边；名字后面同样有「(x次)」（所有背诵任务里提前完成、完成过关、条件过关的总次数，和检查页卡片上一样；下方「本轮全部计划」里的名字也有）；名字卡里列出该生全部计划日期：今天加粗，已过去还没检查的标红，已检查的打 ✓；日期块下方的数字是这天已计划几人。已归档（提前完成 / 完成过关 / 条件过关 / 未过关）的同学名字卡变灰，不能再加计划。还有「把未检查 / 重新过关的都加进来」「清空这天的计划」，下方按日期列出本轮全部计划，点日期可跳过去。

日期可以直接点 本周一～日、下周一～日 共 14 天（按钮上写着具体日期和星期，已经过去的日子显示为灰色，但仍可点开，用来修改历史计划），也可以自选其他日期。

在「🗓️ 计划背诵」子标签里，每个学生块上都会列出 TA 在本轮已有的 全部计划日期（当前选中的那天加粗，已检查的带 ✓），不管现在选的是哪一天；没有计划的显示「暂无计划」。

学生卡片的底色是最新一次检查结果的颜色；如果最后一天是计划（计划日期比最新一次检查还晚，或一次都没检查过），卡片是天蓝色，哪怕之前已经过关；检查之后卡片就回到检查结果的颜色。卡片上不再写状态文字，每行一个日期：检查记录前面是该结果颜色的小圆点，计划前面是 🗓️；到了计划那天卡片会加 粉色边框。同一个同学、同一轮次、同一天只保留一个检查状态，同一天再登记会把原来的状态改成新的（计划不受这个限制，可以同时有多个日期）。登记检查结果不会删除计划，状态和计划可以同时存在。到了计划那天（或之后）登记过检查，这条计划就算完成：不再提醒、卡片上不再显示，但仍保留在检查弹窗的「背诵计划」里（标注 ✓ 已检查）。不需要的计划可以在检查弹窗或时间看板里手动取消。

⏰ 时间看板

默认显示 所有未来的背诵计划，也可以切换为只看未来 7/14/30 天。已逾期的（计划日期已过还没检查）排最上面，然后按日期列出；每条后面标出该同学当前的状态。每条都可以直接点「检查」登记，或「取消计划」。

总览 / 学生趋势

总览：学生 × 轮次色块表。每个格子按这个同学在该轮的每一次检查分成几段，从左到右是第一次、第二次、第三次……（按时间从旧到新），每次一样宽，颜色是那次的结果：提前完成、完成过关、条件过关、重新过关、未过关（例如先重新过关两次、第三次完成过关：黄、黄、绿各占 1/3）；中间的数字是检查次数，灰色表示还没检查。最右一列是按当前状态统计的过关数（提前完成也算过关）。分组跟左侧列表一致：点列头上方的分组名可以折叠 / 展开；按住列头左右拖动可以调整顺序（和检查页左侧列表联动，但倒过来排：列表最上面的在总览最右边，分组和分组里的轮次都倒过来；检查页列表的顺序不变），折叠后该分组缩成一列，显示每个同学在这组里过关几轮（如 2/3）。学生趋势（「背诵」页的「📈 学生趋势」标签）：该生每个轮次的状态、检查次数、首次过关日期和用时，以及完整检查历史（含每次检查的评语）。

提醒

  • 导航栏「背诵」上的数字角标 = 今天的背诵计划 + 已逾期的计划人次（有逾期时为红色）。
  • 每天第一次打开应用时会弹出提示；在主页「设置」里开启 背诵计划系统通知 后还会弹出系统通知。
提醒只会在 打开应用（或切回应用窗口）时 出现，应用关闭时无法推送。建议每天上课前打开一次看板。

考试情况

  • 新建考试：名称、日期、满分。
  • 录入成绩：按学号逐个输入，按 Enter 跳到下一个，留空表示缺考。
  • 导入 TXT：粘贴文本或选择 .txt 文件，先显示预览（匹配成功几人、哪些姓名名单里没有、哪些行无法识别），确认后才写入。姓名、成绩、班级排名必填，年级排名可不填（显示 NA）。
  • 导出 TXT：第一行是表头「姓名 得分 班级排名 年级排名」，下面每行同样的「姓名 成绩 班级排名 年级排名」格式（没有年级排名写 NA），按学号排序，可直接再导入（表头行会自动跳过）。
  • 每场考试显示参考人数、平均分、最高/最低分、及格率（及格线在主页设置，默认 60%）、分数段分布和排名表（依次是班级排名、年级排名、姓名、成绩、得分率，学号在最右边；没有年级排名显示 NA）。
  • 学生趋势（导航栏「📈 学生趋势」页的「📋 考试趋势」块）：某个学生历次考试的原始分（默认，可切换成得分率）折线，与班级平均对比，另有一条浅绿色的班级百分位线（默认打开的「原始分」界面里看右边的 0～100% 刻度，左边是分数；切到「得分率」界面时和得分率共用左边的 0～100%，没有右边刻度。百分位 = 超过了班里百分之几的同学，第一名 100%、最后一名 0%，同分不算超过，缺考的同学不计入；该生缺考的那次没有点）（折线图与成绩表左右并排），以及每次的班级排名、年级排名和平均班级排名。成绩表每一行最前面有个小眼睛：点一下，这场考试就不画进折线图（这一行变淡、眼睛带斜线），再点一下恢复；表头那个小眼睛是总开关，两个状态来回切换：考试都在显示时点一下全部隐藏，只要有隐藏的点一下全部显示。只影响折线图，上面的统计和表格不变；隐藏的选择会记住，换学生、刷新页面后也一样。

TXT 成绩格式

杨迪 101 3 25
罗门 103 1 NA

每行一个学生，依次是 姓名、成绩、班级排名、年级排名，之间用空格（全角空格、Tab、逗号也可以）。姓名、成绩、班级排名必须有；年级排名可以不写，或写 NA，就显示为 NA。排名要是正整数。姓名要与名单完全一致。第一行可以是「姓名 得分 班级排名 年级排名」这样的表头，导入时自动跳过。手工「录入成绩」的学生没有导入排名时，班级排名按分数自动计算，年级排名显示 NA。

学生趋势

点顶部导航栏最右边的「📈 学生趋势」，一个学生的情况分四块从上到下排在同一页：📝 作业趋势、🗣️ 背诵趋势、📋 考试趋势、🗂️ 其他情况，往下滚动就能连着看。时间轴色条和折线图都是旧在左、新在右；成绩表、问题记录、检查历史等列表是最新的在最上面。页面最上面有一个固定不动的选择栏（不会随页面滚动）：上一排四个按钮，点哪个就快速定位到哪一块（滚动时高亮也会跟着变）；下面是全班「学号 姓名」小块，点哪个同学就看哪个同学，四块都会一起切换。点击任何地方的学生姓名（包括作业登记、背诵检查弹窗标题里的姓名）也会跳到这里：在作业页点就定位到作业趋势，背诵页是背诵趋势，考试页是考试趋势，其他地方沿用上次看的那类。作业趋势的时间轴色块可以点击，定位到下面「问题记录」里该作业那一条；点「问题记录」里的作业名称、或背诵趋势检查历史里的任务名称，会跳到作业 / 背诵页对应的那一项，并让该学生的卡片闪烁三秒（点日期不跳转）。考试趋势表格里点考试名称，也会跳到考试页对应的那场考试，并让该学生的成绩行闪烁。跳转之后，左上角会出现一个返回小按钮（↩），点它回到刚才点击的地方（包括滚动到的位置）；从作业 / 背诵 / 考试等页面点学生姓名跳到学生趋势时也一样；点一次回去后按钮就消失，右键点它则不跳转、直接关掉按钮；没点的话它会一直留着，直到你再次从学生趋势跳转（更新位置）或刷新 / 关闭页面。适合家长会、个别谈话时使用。

🔍 拼音找人

  • 学生趋势顶部选择栏（「📝 作业趋势…」四个按钮右边），以及作业、背诵、考试每一项右上角「编辑」按钮左边，都有一个窄的找人输入框（框里写着「请键入...」）。找到几人显示在框里的右侧。
  • 输入拼音字母或汉字都行，也可以用语音输入。空格、标点、数字会自动忽略，不分大小写。每加一个或删一个字就重新找一次，读音对得上的学生会闪金框（和从学生趋势跳过来定位学生的效果一样），闪完留一个不动的框，页面会滚到第一个；输入框右边显示找到几人，找不到显示「无」。
  • 只比读音，不比汉字：同音字也能找到，所以语音输入打错字没关系。输入的拼音是名字完整拼音的开头就算找到。例如班里有李四（lisi）和里乌（liwu）：输入 L、LI 或「李」两人都标出来；输入 LIW、「礼物」或「李武」只标出里乌。多音字每个读音都算（如「曾」zeng / ceng）；ü 用 v 或 u 都行（lv、lu 都能找到「吕」）。
  • 在学生趋势里，一找到匹配的人就直接切换到第一个，下面四块显示这个同学的情况；按 Enter 切换到下一个找到的同学（输入法还在拼字时不切换，选好字后再切）。
  • Enter 依次跳到下一个找到的学生。Esc 在任何地方按都会清空当前这一页的找人框（不用先点输入框），其他页面的找人框不受影响。四处找人框各自记住输入的内容，切换到别的页面再切回来还在，只有刷新或关闭网页后才全部清空；清空后光标自动回到这一页的找人框（框里本来就是空的也一样），可以马上输入下一个名字。弹窗开着时按 Esc，弹窗原来的反应照旧（比如关掉弹窗），找人框也同时清空，但光标不会跳回找人框，免得打断弹窗里的操作；正在别的输入框里打字（比如写其他情况的记录）时按 Esc 也不会跳走。改状态、换作业等页面刷新后，输入的内容会保留，框照样标着。不用联网。

🗂️ 其他情况

  • 用来记录不属于作业、背诵、考试的零散情况，比如学情记录、谈话要点。页面分左右两栏：左边新增记录（日期、内容、照片），右边是这位同学以前的记录（可编辑、删除），写新记录时可以对照着看（手机等窄屏上右边会排到下面）。
  • 添加记录：选记录日期（默认今天）、写内容（也可以只放照片），点「＋ 添加记录」。记录按日期从新到旧排列。
  • 修改：点记录右上角「编辑」，可以改日期、内容和照片；「删除」会先确认。
  • 删除学生会同时删除他的全部记录。

🗂️ 其他（全班横向查看）

  • 导航栏「🗂️ 其他」（在「🗒️ 笔记」左边）把当前班级所有学生的「其他情况」记录并排显示，每个学生一张卡片（按学号排，窗口宽就多排几张），可以横向比较。记录和学生趋势里的「其他情况」是同一份数据。
  • 顶部可勾选「只看有记录的学生」（默认勾上），或在「按内容筛选」里输入关键词，只留下内容里含该词的记录。点学生姓名跳到他的学生趋势；鼠标移到记录上点右上角「编辑 / 删除」。新增记录仍在「📈 学生趋势 → 其他情况」里做。

📷 照片

  • 作业登记、背诵检查（包括编辑检查记录）、其他情况的记录里都有「📷 拍照」和「🖼️ 上传照片」两个按钮，可以加多张。手机、平板上点「拍照」会直接打开系统相机；电脑上点「拍照」会在页面里打开摄像头预览（浏览器会先询问摄像头权限，请点「允许」），点中间的白色圆钮拍照，可以连拍多张，拍完点「完成」；有多个摄像头时可点「切换」。每次打开摄像头前会先扫描一下：没有新插入的摄像头就直接用默认摄像头；发现新的（比如外接了一个摄像头）会弹出选择框让你选，勾选「设为默认摄像头」后以后就不再询问。默认顺序在主页「📷 默认摄像头」里调整：点「扫描摄像头」可更新名单，拖动摄像头名称改先后顺序，排在最前且当前已连接的就是默认摄像头。没有摄像头或不允许使用时会退回到选择图片文件。「上传照片」始终是从设备里选图片。
  • 📱 手机拍（电脑上）：觉得电脑摄像头不清晰时，点「📱 手机拍」，用手机扫屏幕上的二维码，打开拍照页后点「📷 拍照」，会在页面里直接打开摄像头，点白色圆钮拍照，可以连续拍，每拍一张马上传到电脑（取景画面上显示已拍几张、已传几张；支持的手机可以变焦、点画面对焦，拍的是全分辨率照片）。也可以点「📱 用系统相机拍」用手机自带的相机 App（有夜景、HDR 等效果，但部分手机/浏览器拍完不会回到页面），或「🖼️ 从相册选」。每张照片以电脑的确认为准：显示「✓ 电脑已收到」才算传成功，没收到确认会自动重发，不会重复。照片会先存在手机上：网不好时刷新拍照页、或者把页面关掉再打开，没送到的照片都还在（列表上方会写「还有 N 张没送到电脑」），连上后自动接着发；电脑确认收到后手机上的这份才删掉，不想发的可以点照片右上角的「✕」手动删除。手机第一次扫码后会记住电脑，以后只要电脑上打开这个窗口，手机打开同一个页面（可加书签/主屏幕）就自动连上，不用再扫码。照片是手机直连电脑传输的；需要联网，且只能在线上网址使用。和 Windows「手机连接」不冲突。电脑上的窗口点「完成」关闭。
    连不上怎么办：窗口和拍照页都会说明卡在哪一步——「电脑不在线」说明电脑上没打开「📱 手机拍」窗口；「找到电脑了，但连不通」说明两边网络之间打不通，最有效的办法是让电脑连手机热点，或者让手机和电脑连同一个 WiFi（学校、单位 WiFi 和访客网络常常不允许设备互连）；不要用微信扫码，用手机自带的相机或浏览器扫。展开「连接诊断」可以看到更多细节，两边显示的配对码末 4 位应该一致。
    拍了照没传过去？先展开拍照页的「连接诊断」，点「复制日志」，把日志发给开发者，就能看出卡在哪一步。拍照时手机会把网页暂时挂起，回到网页后会自动检查连接、断了就重连，没送到的照片会自动重发（不会重复）；照片上的小标签会显示「发送中」「等待重发」「✓ 已发送」。如果手机提示「刚才拍的照片没有回到这个页面」，说明手机在拍照时把网页关掉了，用「🖼️ 从相册选」把那张发过去即可。照片标着「电脑读不了」时，多半是手机存成了 HEIC 格式，把相机设置里的照片格式改成「兼容性最佳」或「JPG」。手机已连上时，关掉「手机拍」窗口后连接会再保持 2 分钟（主页「⚙️ 设置」里「手机拍：关窗后保持连接」可改，填 0 = 关窗即断开），期间换一块再点「手机拍」会直接复用，不用重新连接；窗口关着时手机拍的照片先留在手机上（标着「电脑窗口关着，打开后自动发」），在电脑上点「手机拍」打开窗口后会自动发过去。
    电脑显示「已连接」、手机却卡在「正在连接牵线服务器」？1.40.0 起手机 8 秒连不上牵线服务器会自动换一个连接重试，一直连不上会提示检查手机网络；手机刷新或关掉拍照页时，电脑会马上改回「等待手机连接」，手机几秒没有动静时电脑显示「手机暂时没有回应」（在用系统相机或锁屏时也会这样，回来后自动重连）。电脑这边也不会丢：照片传到电脑后、保存进记录之前，电脑页面如果刷新或关掉了，那几张还存在电脑上，打开页面时会提醒；在登记弹窗里再点「📱 手机拍」，窗口里点「加到这里」就能找回，点「不要了」删掉。
    传过来的照片怎么压缩？1.41.0 起手机拍的照片传到电脑后不再弹出压缩框，直接按默认档位（主页「⚙️ 设置」里选的）压缩，不裁剪、不旋转，加进照片区；要调整时点那张照片打开编辑框，可以重新选档位、裁剪、旋转，用「‹ 上一张 / 下一张 ›」（或 PageUp / PageDown）快速切到这次新加的其他照片，切换时这张的改动会带上；「取消」不改这张。原图会一直保留到点「完成」保存记录，所以每次重新编辑都是从原图开始，不会越压越糊。笔记里用「📱」手机拍的照片也直接压缩插入（插入后点图片是放大查看，可旋转）。
    手机拍窗口开着时也能删、能改：窗口下面会列出这次收到的照片，每张右上角有「✕」可以删除（删后提示条里可「撤销」），点照片打开和上面一样的编辑框（压缩档位、裁剪、旋转、上一张 / 下一张），改完窗口里的小图也会换成新的；笔记里手机拍插入的照片在这个窗口里同样能删除、重新压缩。编辑框、确认框开着时按 Esc 只关它，手机拍窗口不会一起关。
    竖拍 / 横拍：拍照页点「📷 拍照」后，画面顶部中间有「▯ 竖拍 / ▭ 横拍」按钮，点一下换另一个（会记住）。手机锁了竖屏时横着拿着拍，网页拍出来还是竖的；选「横拍」就会自动转成横的照片（横拍时手机顶端朝左拿，朝右拿会转反），选「竖拍」则横的会转成竖的，方向本来就对的不动，电脑上不用再旋转。「📱 用系统相机拍」和「🖼️ 从相册选」不受这个按钮影响（系统相机自己会定方向）。
    不小心关掉拍照页、重新扫码后显示摄像头「被占用」？1.45.3 起：离开拍照页时会马上放开摄像头；新打开的拍照页会让同一手机浏览器里还开着的旧拍照页让出摄像头和连接（旧页面显示「已停用」，要在那边用就刷新）；摄像头一时还被占着（比如刚才扫码的相机 App 还没放开）时会显示「正在等它放开」，自动重试约 6 秒，不用自己再点。电脑这边也会认出是同一台手机，用新连接顶替旧的，不会把一台手机算成两台。
    拍照页的更新：拍照页每次打开或刷新都是最新版本；一直开着没刷新时，有新版本会在顶部提示「刷新」（没发出去的照片刷新也不会丢），「连接诊断」里能看到拍照页的版本号。
  • 旋转：缩略图上没有旋转按钮，点开照片大图，用底部「↺ 左转 / ↻ 右转」旋转，转完自动记住（不用确认），以后缩略图和大图都是这个方向。
  • 关闭弹窗：登记弹窗里改过文字、选项或增删过照片后，点「取消」、右上角「✕」、框外空白或按 Esc 关闭时，会先问是否放弃修改（「继续编辑」/「放弃修改」）；没改过则直接关闭；点「保存」直接保存。
  • 照片保存为 WebP 格式（iPhone/iPad 上自动用 JPEG）。压缩档位（1.25.0 起新增 0.001 / 0.005 两档和「自定义」档：自定义的默认质量在主页「⚙️ 设置」里改，预览框里可临时改，下次打开恢复设置值；打开时只先算自定义、0.001、0.005、0.01、0.1、0.5 几档，其余点到才算）：「拍照 / 上传照片」收到照片后会弹出预览框（手机拍的照片不弹，直接按默认档压缩，见上一条），上面一排按钮是 WebP 质量 0.01、0.03、0.05、0.08（极限压缩）、0.1、0.2 … 1.0 和「不压缩」，每个按钮下面显示该档的文件大小，点哪个就在上方预览哪个效果（预览区可用鼠标滚轮放大缩小、按住左键拖动平移，手机上双指缩放；也可点「放大到 100%」看小字清不清楚，双击预览区恢复）。预览框里还能快速编辑：用「↺ 左转 / ↻ 右转」旋转，或直接拖动图片四周的边和角来裁剪（松手即生效，可以连续裁几次，「还原编辑」回到最初）；编辑后各档文件大小会重新计算，「不压缩」档此时改为高质量重新保存。预览框支持键盘：← / → 左 / 右转，Enter 确定，Esc 放弃（光标在自定义质量输入框里时 Enter 是应用该数值）。满意后点「确定」，只保存所选的那一份；「放弃这张」则这张不加入。加入后、保存记录前，点照片可以重新打开编辑框从原图再调（多张时可上一张 / 下一张切换）；保存后原图丢弃。数字越大越清楚、文件越大；「不压缩」原样保存。连拍、多选、手机连传的照片会一张一张弹出预览（相机或手机接收窗口还开着时先等着，关掉后再弹）。预览框打开时默认选中的档位在主页「⚙️ 设置」里选。分辨率不会缩小（最长边超过 4096 才等比缩小）。电脑上的摄像头预览会自动要最高分辨率（右上角显示实际分辨率）；摄像头支持时会自动连续对焦，并出现变焦滑块，点一下画面可以重新对焦。如果用手机当电脑摄像头（Phone Link、DroidCam 等），这些功能通常由手机端软件控制，网页里不会出现变焦滑块，要对焦、变焦请在手机端软件里调，或者直接在手机上打开本页拍照。旋转已保存的照片会重新编码一次。点缩略图右上角的「✕」可以移除某张：会先问「确定删除这张照片吗？」，删除后页面上方的提示条里有「撤销」，点一下就放回原来的位置。
  • 加了照片的记录，在各学生趋势（包括其他情况）里会显示缩略图，点击缩略图放大查看（同一条记录有多张照片时，鼠标靠近画面左右两边会出现 ‹ › 按钮可切换，也可按键盘 ← →），放大后可用底部「左转 / 右转」旋转（会记住）、「复位」恢复缩放位置，鼠标滚轮缩放，按住左键拖动；点空白处或按 Esc 关闭。
  • 照片和其他数据一起保存在浏览器里，也会包含在「导出数据库」的文件中；换电脑导入后照片同样恢复。

🎙️ 录音

  • 哪里能录：作业登记、背诵检查（包括编辑检查记录）、学生趋势「其他情况」的新增和编辑，照片按钮那一行最右边有一个红色圆按钮；笔记工具栏里是「🎙️」。点一下开始录音（第一次浏览器会询问麦克风权限，请点「允许」），窗口里显示录了多久和音量条，可以「⏸ 暂停 / ▶ 继续」，点「■ 停止」结束，「取消」或 Esc 不要这一段。一条记录可以录多段。
  • 选压缩档位：停止后会弹出对比框，上面是播放器，下面一排是 6、10、16、24、32 kbps、自定义和「不压缩」，每个按钮下面显示这一档的文件大小，点哪个就播放哪个；切换档位时播放位置不变，方便来回比较。数字越大越清楚、文件越大，默认 16 kbps：说话清楚，1 分钟大约 140 KB。框里还可以临时改自定义码率、采样率、是否去掉开头结尾的静音、立体声（只对这一段有效）。点「确定」只保存选中的那一份，原始录音丢弃；「放弃这段」则不保存。
  • 其他参数：除了码率，还能调采样率（相当于照片的分辨率：越高保留的高音越多、文件越大；说话用 16 kHz 就够清楚）、声道（单声道最省；立体声要麦克风本身是双声道才有用，而且要把码率调高一倍）、去掉开头结尾的静音（按下录音到开口、说完到点停止之间的空白去掉，各留 0.3 秒，中间的停顿不动）、浏览器降噪（降噪、回声消除、自动音量；教室吵时建议开）。
  • 改默认值、试听：在主页「⚙️ 设置」里可以改上面这些的默认值。点「🎙️ 试录一段」录一段（不会保存），在对比框里改参数、逐档试听，满意了点「把这些设为默认」，以后录音就按这个来；「再听上次试录」可以用同一段再试（关掉页面后就没了）。设置存在这台设备的浏览器里，换电脑要重新设。
  • 播放：学生趋势里的作业、背诵记录，背诵检查弹窗下面的记录，其他情况的记录列表，以及笔记里，录音都显示成播放条，直接点播放；同一时间只放一段。要删掉一段：在登记 / 编辑弹窗里点录音右边的「✕」（删除后提示条里可「撤销」），笔记里点录音旁边把光标放好后按 Backspace / Delete。
  • 浏览器：Chrome、Edge、新版 Firefox、Safari 26 以上（iPhone / iPad 要 iOS 26）可以逐档压缩。更早的 Safari、Firefox 安卓版不支持在页面里重新压缩：会直接按默认档的码率录，对比框里只能试听这一份，采样率 / 去静音不起作用。录音要用 https 打开（线上网址就是）；打不开麦克风时按钮会改为选择一个录音文件。
  • 录音和照片一起保存在浏览器里，也包含在「导出数据库」的文件和 OneDrive 备份里，换电脑导入后同样恢复。

笔记

导航栏最右边的「🗒️ 笔记」是一个简易笔记本，用来记想法和与学生谈话的要点。笔记全班级共用，切换班级不会变；也会包含在「导出数据库」文件里。页面分左右两栏，窄屏（手机）上左栏排在上面。

  • 左边是目录：「＋ 新建笔记」新建一篇；「＋ 文件夹」新建文件夹，把笔记拖进文件夹归类（文件夹可折叠、重命名、删除，删除文件夹不会删掉里面的笔记；笔记也能拖动调整顺序、拖出文件夹）。顶部搜索框可搜标题和正文。没手动排过的笔记，最近改过的排在前面。
  • 右边是编辑区：上方标题（可不填，不填就用正文开头当名字），下面是工具栏和正文。工具栏有：撤销 / 重做、加粗、斜体、下划线、删除线、字号（小 / 正常 / 大 / 特大）、文字颜色、背景高亮色（调色板最后的「＋」可选任意颜色）、无序 / 有序列表、待办清单（点方框打钩）、左 / 中 / 右对齐、引用、分割线、清除格式、插入今天日期、插入图片。也可用 Ctrl+B / Ctrl+I / Ctrl+U / Ctrl+Z。从网页或 Word 粘贴文字时只保留上述格式。
  • 自动保存：停止输入不到一秒就保存，标题栏右边显示「已保存」；切换笔记、离开本页前也会先存。没有保存按钮。
  • 图片：点「🖼️ 图片」选图片、点「📷」拍照、电脑上点「📱」用手机拍，也可以直接粘贴（Ctrl+V）或拖入图片。和登记照片一样，会先弹出压缩预览框：可以旋转、拖动四周裁剪，选压缩档位，点「确定」才插入到光标处（用手机拍的不弹，直接按默认档压缩插入；手机拍窗口开着时可以在窗口里删除或点开重新压缩）。点笔记里的图片会放大查看：同一篇笔记里的多张图片可用 ‹ › 或键盘 ← → 左右切换，也能旋转、滚轮缩放。要删除图片：点一下选中它，按 Delete 或 Backspace。
  • 删除笔记：右上角「删除」，会先确认，笔记里的图片一并删除。

安装与更新

  • 主页「应用」里点 安装到桌面（Chrome/Edge 地址栏右侧也有安装图标），之后可以像普通软件一样从桌面打开，断网也能使用。
  • 发布新版本后，打开应用会弹出更新提示：点此完成更新 立即刷新到新版；稍后再说 下次打开再提醒；跳过此版本 这个版本不再提示。更新不会影响你的数据。
  • 主页「检查更新」可以随时查看当前版本的更新内容。
  • 学情看板是独立的应用，和同一网站上的其他应用互不影响。如果 1.9.1 之前就装过，桌面上的图标打开后显示的是别的应用，或者装了一个另一个就没了，把旧的卸载后重新安装一次即可。卸载时不要勾选「同时清除数据」，保险起见先导出一份 .db。

常见问题

日期怎么显示？

界面上的日期都写成 10-29(星期四) 这种格式，月-日后面括号标注星期几。

数据会丢吗？

数据保存在浏览器本地，应用会申请"持久化存储"（主页显示状态）。但清除浏览器数据、换浏览器/电脑都会看不到原来的数据，请定期导出数据库（.db）或上传 OneDrive。数据有改动时，每天第一次打开会提醒你备份（见 数据备份）。

两台电脑能同时用吗？

可以各自使用，但数据不会自动同步。需要转移时：在 A 电脑导出（或上传 OneDrive），在 B 电脑导入（或恢复）——会覆盖 B 上的数据。

学生改名了怎么办？

在名单里点「编辑」直接改名，历史记录都会保留。
