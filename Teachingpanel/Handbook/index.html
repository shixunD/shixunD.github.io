快速开始

  1. 在「主页 → 学生名单」点 批量添加，把「学号 姓名」两列从 Excel 复制粘贴进去。
  2. 每天在「作业」里 新建作业，只需点出没完成的同学（默认全班都是完成）。
  3. 在「背诵」里建一个 轮次（一篇课文/一组古诗），每天抽查几个人并登记结果。
  4. 考完试在「考试」里新建考试，粘贴「姓名 成绩 班级排名 年级排名」即可导入。
  5. 定期在主页点 导出全部数据 备份一次。
所有数据只保存在你当前使用的这个浏览器里，不会上传到任何服务器（除非你主动使用 OneDrive 备份）。

主页

顶部四个概览卡片：今日背诵剩余人数（今天还有未完成背诵计划的学生）、今日作业未补（今天布置的作业里还没补上的人次）、本周背诵剩余人数（本周轮次里，状态不是提前完成 / 完成过关 / 条件过关的学生人次）、本周作业未补（本周布置的作业里还没补上的人次，一人一份作业算一次，累加）。点击卡片直接跳到对应页面。新建 / 编辑背诵轮次时需要选择这个任务设定的具体日期：弹出的日历可前后翻月，点任意一天即选中那一天，它所在的那一周会同时高亮（按周粗略分组，按具体日期精细排序）。

学生名单

  • 名单始终 按学号从小到大 排列。
  • 姓名在同一个班里必须唯一（成绩导入靠姓名匹配）。重名学生请加后缀区分，例如「张三B」。
  • 批量添加支持「学号 姓名」「姓名 学号」或只写姓名（自动接着最大学号编号）；已存在的姓名会跳过。
  • 点击任何地方的学生姓名都会跳到该生的 学生趋势。
  • 删除学生会同时删除他的全部作业、背诵、考试记录。

多班级

顶部导航栏的「🏫 班级名 ▾」可以切换、新建、重命名、删除班级。每个班级的学生和记录相互独立。

导出统计（作业加减分 + 背诵过关）

  • 主页「📤 导出统计」卡片 → 选择内容并导出：左边勾选作业（勾分组夹 = 全选里面的作业，也可以单独取消某一项），右边勾选背诵任务（可多选，也可以不选）。下方立即显示预览，再点 PDF（打印）、Excel、Markdown 或 复制 Markdown。上次的勾选会记住。
  • 作业加减分：一次导出算一个统计周期，N = 勾选的作业总数（不管来自几个分组夹）。全部 N 项都是绿色 +2 分；只差 1 项不是绿色 +1 分（N 至少为 2 才有这一档，N = 1 时只有「绿色 +2 / 否则 0」）；未按要求完成（粉）每项 −0.5，未完成（红）每项 −1；已补改、已补交（蓝）不扣分，但不算绿色。最终得分 = 加分 − 扣分。
  • 背诵加减分：每个背诵任务一列，表头是任务全名，格子里是该任务的得分。先按检查页学生卡片的底色判是否过关（最新一次检查是提前完成 / 完成过关 / 条件过关，且之后没有还未完成的背诵计划）。提前完成 +3；没有计划，或只有一次计划且计划当日过关 +2；有多个计划日期、或计划当日没过关但最终过关 +1；最终没过关（计划中 / 重新过关 / 未过关 / 未检查）−2。报表多出「背诵得分」（各任务相加）和「总分」（作业得分 + 背诵得分）两列。
  • 报表内容：汇总表（学号、学生、各状态数量、加分、扣分、最终得分、背诵 ✓/✗）、全班总分 / 人均 / 全部按时完成人数 / 部分按时完成（差一项）人数、逐项明细色块、背诵未过关名单、仍未补交 / 未补改名单。可按学号或按最终得分排序，标题可以自己改。
  • PDF：会打开浏览器的打印窗口，「打印机 / 目标」选「另存为 PDF」。Excel 有三张表：汇总、逐项明细（格子底色 = 状态）、说明与名单。PDF / 预览里，逐项明细表下方有「作业卡片颜色」「背诵卡片颜色」两行图例。Markdown 里绿色用 ✅、粉色用 🩷、红色用 🔴、已补改 🩵、已补交 💙。
  • 分值可以改：主页「⚙️ 设置 → 导出统计：加减分规则 → 调整」。可改全绿加分、差一项加分、四种非绿色状态各自每项扣几分、背诵四档的分值，以及「条件过关算不算过关」「过关后还有未完成的计划是否判不过关」。
  • 统计以导出那一刻的状态为准。没登记过的学生默认是「完全完成」，所以中途转入的学生在转入前布置的作业上会算绿色。

comment 快捷词

  • 主页「💬 comment 快捷词」卡片里可以添加、编辑（✎，回车保存、Esc 取消）、删除（会先二次确认）、调整顺序（↑↓）。作业和背诵是两套独立的快捷词。
  • 背诵默认有：复习体系混乱、复习体系有条理、书写有一定问题、格式需要改善；作业默认为空，按需添加。
  • 登记作业状态或背诵检查时，点一下快捷词就会 追加 到 comment 末尾（自动用「；」隔开），还可以继续手动输入。

数据备份

  • 📤 导出数据库（.db）：得到一个数据库文件（文件名是导出时间，如 2026-10-29--14-30-05.db），包含所有班级、学生、作业、背诵、考试、计划、学情记录和设置。换电脑时在新电脑上点 📥 导入数据库 选择这个文件即可完整恢复。
  • 这个 .db 是标准的 SQLite 数据库，可以用免费的 DB Browser for SQLite 等工具直接打开，按表（students 学生、homework 作业、homework_records 作业登记、rec_checks 背诵检查、rec_plans 背诵计划、exam_scores 成绩……）查看数据。
  • 导入会 覆盖 当前全部数据，导入前建议先导出一份。选错文件（不是本应用导出的数据库）时会提示错误，当前数据不会被改动。
  • OneDrive 云备份：每次上传都是一份新的带时间戳的 .db 快照，可在历史列表中选择任一份恢复（覆盖本地）。它不是自动双向同步。首次使用时点「☁️ OneDrive 云备份」→「登录 OneDrive」，用个人 Microsoft 账户登录并同意授权即可；应用只能读写 OneDrive 里「应用 / TeachingPanel」这一个文件夹，看不到你的其他文件。

作业情况

颜色含义
深绿完全完成（新作业默认）
红未完成
粉红未按要求完成
深蓝已补交（原来未完成，已补上）

登记

  • 调整作业顺序：左侧作业列表可以按住某一项上下拖动换位置（拖到目标的上半部分 = 插到它前面，下半部分 = 插到它后面）。拖过之后顺序会记住；之后新建的作业仍排在最上面。这只影响左侧列表的显示顺序，趋势、统计仍按日期计算。
  • 分组：点列表上方的「＋ 分组」新建一个分组夹（可以用来分单元、分阶段）。把作业拖到分组夹的标题上就放进去了，拖到分组夹里某一项的上 / 下半部分可以排到它前 / 后，拖到列表最底部的空白处可以移出分组；分组夹本身也可以拖动换位置。点分组夹的标题可以折叠 / 展开，右边的 ✎ 重命名、✕ 删除（只删分组夹，里面的作业会回到列表里，不会被删除）。
  • 点 新建作业，日期直接点 本周一～日、下周一～日 的日期块（默认今天，找不到再用日历框），填标题（可留空自动命名）。
  • 点击学生卡片 → 选择状态并写 comment（可以点快捷词快速填入）。
  • 红色/粉色卡片右上角的 「补」：学生补交后点一下，在弹出的确认框里点「确认已补上」，才会变成对应的蓝色；点错了可以点提示条上的「撤销」。

总览

学生 × 作业的色块表，一眼看出谁经常没完成。可按时间范围筛选；带白色小角的格子有 comment；最右列是"未补上"数量。列的顺序和分组跟左侧列表一致：同一分组的列上方有分组名，点分组名可以折叠 / 展开；按住列头左右拖动可以调整列的顺序（和左侧列表是同一个顺序：左侧列表靠前的，总览里靠左）（和左侧列表共用，折叠后该分组缩成一列，显示每个同学在这组里未补几项）。

欠交清单

按 作业 分组列出还没补上的同学（红/粉），最新的作业在最前面；点作业标题可跳到该作业的登记页。

学生补交后点「已补上」，确认 后才会生效；之后页面顶部会出现提示条，8 秒内点「撤销」即可恢复原状态（comment 也会保留）。

学生趋势

作业登记页的统计行并排显示「按时完成 xx% | 补改完成 xx%」（补改完成含已补交 / 已补改）。

在导航栏「📈 学生趋势」页的「📝 作业趋势」块里看：某个学生的按时完成率、最终完成率（含补交）、各状态次数、时间轴色条、每周完成率折线和全部 comment。

背诵情况

背诵按 轮次 管理：一个轮次就是一项背诵任务（例如「第三单元古诗两首」），不分日期——每天能查几个就查几个，每次检查都会记录日期。

颜色含义
灰还没检查
深绿提前完成（过关里做得特别好的，统计时算作过关）
绿完成过关
黄需要重新过关
红未过关
浅绿条件过关（勉强过关，算作过关但不太理想）
浅天蓝已安排计划背诵（卡片上显示计划日期和星期）
粉色边框今天需要检查（今天有背诵计划——不管是第一次背还是重新过关）

检查

  • 左侧选轮次，点学生卡片登记（打开时检查日期默认是今天：今天已有检查记录就自动选中它的结果并载入备注，没有就结果留空，要自己点；点掉已选的日期（再点一次）就不登记这次的检查结果，只处理计划，再点一次已选的日期可以取消；日期块里「今天」是灰色粗边框）：结果（提前完成 / 完成过关 / 条件过关 / 重新过关 / 未过关，再点一次可取消）、检查日期、备注；检查日期下面是 🗓️ 计划背诵日期（不用再点开关，选了日期就是要计划；该同学已有的计划日期会直接显示为选中，再点一次就取消）。每个日期只有一个检查状态、一个计划：点到已有记录的日期会自动载入那天的结果和备注可以直接改；改了没保存就关窗口时会提示。左侧的轮次可以 按住拖动 调整上下顺序；也可以像作业一样用「＋ 分组」建分组夹，把轮次拖进去 / 拖出来，点分组夹标题折叠 / 展开。
  • 重新过关 / 未过关只是一个状态，不带日期。可以顺便在「🗓️ 计划背诵日期」里点选哪天再背（可多选，会加入背诵计划）；不选日期也能直接保存。
  • 日期都用日期块点选：弹窗里直接列出 本周一～日、下周一～日 的日期块（标注具体日期和星期），点一下即可；实在不在这两周内，再用最下面「其他」的日历框选。检查日期默认就是今天，只能选今天及以前。
  • 学生的当前颜色 = 最近一次检查的结果（有未完成的计划时底色浅绿，状态用小圆点标出）；卡片上同时显示状态、最近检查日期和计划日期（多个计划时显示 +N）。弹窗底部能看到本轮所有检查记录：登记错了可以点 编辑（修改结果、检查日期、备注，保存后回到检查弹窗），或点 删除。
  • 「提前完成」的限制：登记提前完成后这一轮就算过关，不能再登记其他状态、不能再加计划日期（之前已有的计划保留），只能修改那条记录的备注和照片（想改状态要先删掉这条记录）；之前登记过重新过关 / 未过关的同学不能再选提前完成。不能选的按钮会变灰。
  • 筛选按钮可以只看未检查、重新过关、未过关、完成过关、提前完成、条件过关的同学。

计划背诵

提前安排某个同学哪天来背。有两种方式：

  • 点学生卡片，在检查弹窗里的 🗓️ 计划背诵日期 选日期（可以选多个），会显示在「背诵趋势 → 检查历史」里（检查历史按背诵任务设定的日期排序（近的在前），再按任务所属的周分组（不是检查日期），相邻两周之间有一根虚线分隔；左边的竖线把同一个背诵任务的记录串在一起，不同任务各一条线）。它和检查结果互不影响：可以只加计划，也可以同时登记过关/重背/未过关并加计划。
  • 背诵页顶部的 🗓️ 计划背诵 子标签（检查页轮次右上角的同名按钮也会跳过去）：选轮次 → 点日期 → 点学生，就加入这天的计划；再点一次取消，自动保存。 已计划但还没过关的同学，名字卡左侧的色条是天蓝色（其他按状态显示颜色）；选中某一天时，这天有计划的同学多一圈蓝边；名字卡里列出该生全部计划日期：今天加粗，已过去还没检查的标红，已检查的打 ✓；日期块下方的数字是这天已计划几人。还有「把未过关的都加进来」「清空这天的计划」，下方按日期列出本轮全部计划，点日期可跳过去。

日期可以直接点 本周一～日、下周一～日 共 14 天（按钮上写着具体日期和星期，已经过去的日子显示为灰色，但仍可点开，用来修改历史计划），也可以自选其他日期。

在「🗓️ 计划背诵」子标签里，每个学生块上都会列出 TA 在本轮已有的 全部计划日期（当前选中的那天加粗，已检查的带 ✓），不管现在选的是哪一天；没有计划的显示「暂无计划」。

学生卡片的底色是最新一次检查结果的颜色；如果最后一天是计划（计划日期比最新一次检查还晚，或一次都没检查过），卡片是天蓝色，哪怕之前已经过关；检查之后卡片就回到检查结果的颜色。卡片上不再写状态文字，每行一个日期：检查记录前面是该结果颜色的小圆点，计划前面是 🗓️；到了计划那天卡片会加 粉色边框。同一个同学、同一轮次、同一天只保留一个检查状态，同一天再登记会把原来的状态改成新的（计划不受这个限制，可以同时有多个日期）。登记检查结果不会删除计划，状态和计划可以同时存在。到了计划那天（或之后）登记过检查，这条计划就算完成：不再提醒、卡片上不再显示，但仍保留在检查弹窗的「背诵计划」里（标注 ✓ 已检查）。不需要的计划可以在检查弹窗或时间看板里手动取消。

⏰ 时间看板

默认显示 所有未来的背诵计划，也可以切换为只看未来 7/14/30 天。已逾期的（计划日期已过还没检查）排最上面，然后按日期列出；每条后面标出该同学当前的状态。每条都可以直接点「检查」登记，或「取消计划」。

总览 / 学生趋势

总览：学生 × 轮次色块表。每个格子按这个同学在该轮 所有检查 的结果数量分成几段：提前完成、完成过关、条件过关、重新过关、未过关，从左到右排列，次数越多那一段越宽（例如完成过关 1 次、未过关 2 次：绿占 1/3、红占 2/3）；中间的数字是检查次数，灰色表示还没检查。最右一列是按当前状态统计的过关数（提前完成也算过关）。分组跟左侧列表一致：点列头上方的分组名可以折叠 / 展开；按住列头左右拖动可以调整顺序（和左侧列表同一个顺序，列表靠前 = 总览靠左，所以背诵总览现在也是新的在左边），折叠后该分组缩成一列，显示每个同学在这组里过关几轮（如 2/3）。学生趋势（「背诵」页的「📈 学生趋势」标签）：该生每个轮次的状态、检查次数、首次过关日期和用时，以及完整检查历史（含每次检查的评语）。

提醒

  • 导航栏「背诵」上的数字角标 = 今天的背诵计划 + 已逾期的计划人次（有逾期时为红色）。
  • 每天第一次打开应用时会弹出提示；在主页「设置」里开启 背诵计划系统通知 后还会弹出系统通知。
提醒只会在 打开应用（或切回应用窗口）时 出现，应用关闭时无法推送。建议每天上课前打开一次看板。

考试情况

  • 新建考试：名称、日期、满分。
  • 录入成绩：按学号逐个输入，按 Enter 跳到下一个，留空表示缺考。
  • 导入 TXT：粘贴文本或选择 .txt 文件，先显示预览（匹配成功几人、哪些姓名名单里没有、哪些行无法识别），确认后才写入。姓名、成绩、班级排名必填，年级排名可不填（显示 NA）。
  • 导出 TXT：同样的「姓名 成绩 班级排名 年级排名」格式（没有年级排名写 NA），按学号排序，可直接再导入。
  • 每场考试显示参考人数、平均分、最高/最低分、及格率（及格线在主页设置，默认 60%）、分数段分布和排名表（班级排名、年级排名；没有年级排名显示 NA）。
  • 学生趋势（导航栏「📈 学生趋势」页的「📋 考试趋势」块）：某个学生历次考试的得分率（或原始分）折线，与班级平均对比（折线图与成绩表左右并排），以及每次的班级排名、年级排名和平均班级排名。

每行一个学生，依次是 姓名、成绩、班级排名、年级排名，之间用空格（全角空格、Tab、逗号也可以）。姓名、成绩、班级排名必须有；年级排名可以不写，或写 NA，就显示为 NA。排名要是正整数。姓名要与名单完全一致。手工「录入成绩」的学生没有导入排名时，班级排名按分数自动计算，年级排名显示 NA。

学生趋势

点顶部导航栏最右边的「📈 学生趋势」，一个学生的情况分四块从上到下排在同一页：📝 作业趋势、🗣️ 背诵趋势、📋 考试趋势、🗂️ 其他情况，往下滚动就能连着看。页面最上面有一个固定不动的选择栏（不会随页面滚动）：上一排四个按钮，点哪个就快速定位到哪一块（滚动时高亮也会跟着变）；下面是全班「学号 姓名」小块，点哪个同学就看哪个同学，四块都会一起切换。点击任何地方的学生姓名（包括作业登记、背诵检查弹窗标题里的姓名）也会跳到这里：在作业页点就定位到作业趋势，背诵页是背诵趋势，考试页是考试趋势，其他地方沿用上次看的那类。作业趋势的时间轴色块可以点击，定位到下面「问题记录」里该作业那一条；点「问题记录」里的作业名称、或背诵趋势检查历史里的任务名称，会跳到作业 / 背诵页对应的那一项，并让该学生的卡片闪烁三秒（点日期不跳转）。考试趋势表格里点考试名称，也会跳到考试页对应的那场考试，并让该学生的成绩行闪烁。跳转之后，左上角会出现一个返回小按钮（↩），点它回到刚才点击的地方（包括滚动到的位置）；从作业 / 背诵 / 考试等页面点学生姓名跳到学生趋势时也一样；点一次回去后按钮就消失，右键点它则不跳转、直接关掉按钮；没点的话它会一直留着，直到你再次从学生趋势跳转（更新位置）或刷新 / 关闭页面。适合家长会、个别谈话时使用。

🗂️ 其他情况

  • 用来记录不属于作业、背诵、考试的零散情况，比如学情记录、谈话要点。页面分左右两栏：左边新增记录（日期、内容、照片），右边是这位同学以前的记录（可编辑、删除），写新记录时可以对照着看（手机等窄屏上右边会排到下面）。
  • 添加记录：选记录日期（默认今天）、写内容（也可以只放照片），点「＋ 添加记录」。记录按日期从新到旧排列。
  • 修改：点记录右上角「编辑」，可以改日期、内容和照片；「删除」会先确认。
  • 删除学生会同时删除他的全部记录。

📷 照片

  • 作业登记、背诵检查（包括编辑检查记录）、其他情况的记录里都有「📷 拍照」和「🖼️ 上传照片」两个按钮，可以加多张。手机、平板上点「拍照」会直接打开系统相机；电脑上点「拍照」会在页面里打开摄像头预览（浏览器会先询问摄像头权限，请点「允许」），点中间的白色圆钮拍照，可以连拍多张，拍完点「完成」；有多个摄像头时可点「切换」。每次打开摄像头前会先扫描一下：没有新插入的摄像头就直接用默认摄像头；发现新的（比如外接了一个摄像头）会弹出选择框让你选，勾选「设为默认摄像头」后以后就不再询问。默认顺序在主页「📷 默认摄像头」里调整：点「扫描摄像头」可更新名单，拖动摄像头名称改先后顺序，排在最前且当前已连接的就是默认摄像头。没有摄像头或不允许使用时会退回到选择图片文件。「上传照片」始终是从设备里选图片。
  • 📱 手机拍（电脑上）：觉得电脑摄像头不清晰时，点「📱 手机拍」，用手机扫屏幕上的二维码，打开拍照页后点「📷 拍照」，会在页面里直接打开摄像头，点白色圆钮拍照，可以连续拍，每拍一张马上传到电脑（取景画面上显示已拍几张、已传几张；支持的手机可以变焦、点画面对焦，拍的是全分辨率照片）。也可以点「📱 用系统相机拍」用手机自带的相机 App（有夜景、HDR 等效果，但部分手机/浏览器拍完不会回到页面），或「🖼️ 从相册选」。每张照片以电脑的确认为准：显示「✓ 电脑已收到」才算传成功，没收到确认会自动重发，不会重复。手机第一次扫码后会记住电脑，以后只要电脑上打开这个窗口，手机打开同一个页面（可加书签/主屏幕）就自动连上，不用再扫码。照片是手机直连电脑传输的；需要联网，且只能在线上网址使用。和 Windows「手机连接」不冲突。电脑上的窗口点「完成」关闭。
    连不上怎么办：窗口和拍照页都会说明卡在哪一步——「电脑不在线」说明电脑上没打开「📱 手机拍」窗口；「找到电脑了，但连不通」说明两边网络之间打不通，最有效的办法是让电脑连手机热点，或者让手机和电脑连同一个 WiFi（学校、单位 WiFi 和访客网络常常不允许设备互连）；不要用微信扫码，用手机自带的相机或浏览器扫。展开「连接诊断」可以看到更多细节，两边显示的配对码末 4 位应该一致。
    拍了照没传过去？先展开拍照页的「连接诊断」，点「复制日志」，把日志发给开发者，就能看出卡在哪一步。拍照时手机会把网页暂时挂起，回到网页后会自动检查连接、断了就重连，没送到的照片会自动重发（不会重复）；照片上的小标签会显示「发送中」「等待重发」「✓ 已发送」。如果手机提示「刚才拍的照片没有回到这个页面」，说明手机在拍照时把网页关掉了，用「🖼️ 从相册选」把那张发过去即可。照片标着「电脑读不了」时，多半是手机存成了 HEIC 格式，把相机设置里的照片格式改成「兼容性最佳」或「JPG」。手机已连上时，关掉「手机拍」窗口后连接会再保持 2 分钟（主页「⚙️ 设置」里「手机拍：关窗后保持连接」可改，填 0 = 关窗即断开），期间换一块再点「手机拍」会直接复用，不用重新连接；窗口关着时手机拍的照片不会被接收，要先在电脑上点「手机拍」。
  • 旋转：缩略图上没有旋转按钮，点开照片大图，用底部「↺ 左转 / ↻ 右转」旋转，转完自动记住（不用确认），以后缩略图和大图都是这个方向。
  • 关闭弹窗：登记弹窗里改过文字、选项或增删过照片后，点「取消」、右上角「✕」、框外空白或按 Esc 关闭时，会先问是否放弃修改（「继续编辑」/「放弃修改」）；没改过则直接关闭；点「保存」直接保存。
  • 照片保存为 WebP 格式（iPhone/iPad 上自动用 JPEG）。压缩档位（1.25.0 起新增 0.001 / 0.005 两档和「自定义」档：自定义的默认质量在主页「⚙️ 设置」里改，预览框里可临时改，下次打开恢复设置值；打开时只先算自定义、0.001、0.005、0.01、0.1、0.5 几档，其余点到才算）：「拍照 / 手机拍 / 上传照片」收到照片后会弹出预览框，上面一排按钮是 WebP 质量 0.01、0.03、0.05、0.08（极限压缩）、0.1、0.2 … 1.0 和「不压缩」，每个按钮下面显示该档的文件大小，点哪个就在上方预览哪个效果（预览区可用鼠标滚轮放大缩小、按住左键拖动平移，手机上双指缩放；也可点「放大到 100%」看小字清不清楚，双击预览区恢复）。预览框里还能快速编辑：用「↺ 左转 / ↻ 右转」旋转，或直接拖动图片四周的边和角来裁剪（松手即生效，可以连续裁几次，「还原编辑」回到最初）；编辑后各档文件大小会重新计算，「不压缩」档此时改为高质量重新保存。预览框支持键盘：← / → 左 / 右转，Enter 确定，Esc 放弃（光标在自定义质量输入框里时 Enter 是应用该数值）。满意后点「确定」，只保存所选的那一份，收到的完整原图丢弃；「放弃这张」则这张不加入。数字越大越清楚、文件越大；「不压缩」原样保存。连拍、多选、手机连传的照片会一张一张弹出预览（相机或手机接收窗口还开着时先等着，关掉后再弹）。预览框打开时默认选中的档位在主页「⚙️ 设置」里选。分辨率不会缩小（最长边超过 4096 才等比缩小）。电脑上的摄像头预览会自动要最高分辨率（右上角显示实际分辨率）；摄像头支持时会自动连续对焦，并出现变焦滑块，点一下画面可以重新对焦。如果用手机当电脑摄像头（Phone Link、DroidCam 等），这些功能通常由手机端软件控制，网页里不会出现变焦滑块，要对焦、变焦请在手机端软件里调，或者直接在手机上打开本页拍照。旋转已保存的照片会重新编码一次。点缩略图右上角的「✕」可以移除某张：会先问「确定删除这张照片吗？」，删除后页面上方的提示条里有「撤销」，点一下就放回原来的位置。
  • 加了照片的记录，在各学生趋势（包括其他情况）里会显示缩略图，点击缩略图放大查看（同一条记录有多张照片时，鼠标靠近画面左右两边会出现 ‹ › 按钮可切换，也可按键盘 ← →），放大后可用底部「左转 / 右转」旋转（会记住）、「复位」恢复缩放位置，鼠标滚轮缩放，按住左键拖动；点空白处或按 Esc 关闭。
  • 照片和其他数据一起保存在浏览器里，也会包含在「导出数据库」的文件中；换电脑导入后照片同样恢复。

笔记

导航栏最右边的「🗒️ 笔记」是一个简易笔记本，用来记想法和与学生谈话的要点。笔记全班级共用，切换班级不会变；也会包含在「导出数据库」文件里。页面分左右两栏，窄屏（手机）上左栏排在上面。

  • 左边是目录：「＋ 新建笔记」新建一篇；「＋ 文件夹」新建文件夹，把笔记拖进文件夹归类（文件夹可折叠、重命名、删除，删除文件夹不会删掉里面的笔记；笔记也能拖动调整顺序、拖出文件夹）。顶部搜索框可搜标题和正文。没手动排过的笔记，最近改过的排在前面。
  • 右边是编辑区：上方标题（可不填，不填就用正文开头当名字），下面是工具栏和正文。工具栏有：撤销 / 重做、加粗、斜体、下划线、删除线、字号（小 / 正常 / 大 / 特大）、文字颜色、背景高亮色（调色板最后的「＋」可选任意颜色）、无序 / 有序列表、待办清单（点方框打钩）、左 / 中 / 右对齐、引用、分割线、清除格式、插入今天日期、插入图片。也可用 Ctrl+B / Ctrl+I / Ctrl+U / Ctrl+Z。从网页或 Word 粘贴文字时只保留上述格式。
  • 自动保存：停止输入不到一秒就保存，标题栏右边显示「已保存」；切换笔记、离开本页前也会先存。没有保存按钮。
  • 图片：点「🖼️ 图片」选图片、点「📷」拍照、电脑上点「📱」用手机拍，也可以直接粘贴（Ctrl+V）或拖入图片。和登记照片一样，会先弹出压缩预览框：可以旋转、拖动四周裁剪，选压缩档位，点「确定」才插入到光标处。点笔记里的图片会放大查看：同一篇笔记里的多张图片可用 ‹ › 或键盘 ← → 左右切换，也能旋转、滚轮缩放。要删除图片：点一下选中它，按 Delete 或 Backspace。
  • 删除笔记：右上角「删除」，会先确认，笔记里的图片一并删除。

安装与更新

  • 主页「应用」里点 安装到桌面（Chrome/Edge 地址栏右侧也有安装图标），之后可以像普通软件一样从桌面打开，断网也能使用。
  • 发布新版本后，打开应用会弹出更新提示：点此完成更新 立即刷新到新版；稍后再说 下次打开再提醒；跳过此版本 这个版本不再提示。更新不会影响你的数据。
  • 主页「检查更新」可以随时查看当前版本的更新内容。
  • 学情看板是独立的应用，和同一网站上的其他应用互不影响。如果 1.9.1 之前就装过，桌面上的图标打开后显示的是别的应用，或者装了一个另一个就没了，把旧的卸载后重新安装一次即可。卸载时不要勾选「同时清除数据」，保险起见先导出一份 .db。

常见问题

日期怎么显示？

界面上的日期都写成 10-29(星期四) 这种格式，月-日后面括号标注星期几。

数据会丢吗？

数据保存在浏览器本地，应用会申请"持久化存储"（主页显示状态）。但清除浏览器数据、换浏览器/电脑都会看不到原来的数据，请定期导出数据库（.db）或上传 OneDrive。

两台电脑能同时用吗？

可以各自使用，但数据不会自动同步。需要转移时：在 A 电脑导出（或上传 OneDrive），在 B 电脑导入（或恢复）——会覆盖 B 上的数据。

学生改名了怎么办？

在名单里点「编辑」直接改名，历史记录都会保留。
